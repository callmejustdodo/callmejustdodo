# Local webfonts

Unmodified Latin WOFF2 files served by the Google Fonts CSS API, downloaded 2026-09-28 (regular) and 2026-10-02 (italic). The corresponding SIL Open Font License files are included beside each family.

- Instrument Serif Regular and Italic: https://fonts.google.com/specimen/Instrument+Serif
- EB Garamond Regular and Italic: https://fonts.google.com/specimen/EB+Garamond
- Radley Regular and Italic: https://fonts.google.com/specimen/Radley
- DM Sans variable: https://fonts.google.com/specimen/DM+Sans
- DM Mono Regular: https://fonts.google.com/specimen/DM+Mono

Radley is the selected display face, including its genuine italic. DM Sans is used for body text and DM Mono for utility labels. Instrument Serif and EB Garamond files are retained as design-study assets but are not loaded by the page. No remote font request is required at runtime.
